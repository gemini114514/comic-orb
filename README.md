# 漫画工房悬浮球（Comic Orb）

漫画工房悬浮球是面向 SillyTavern 的一体化漫画生成扩展。它能按楼层提取非 User 剧情，经过可配置正则与可选 MVU 状态处理，再选择“直接分镜”或“演绎→并发分镜”工作流，把严格分页 JSON 交给绘画模型并将成品自动写回原聊天。扩展内置三套相互独立的 OpenAI 兼容 API 实例库、模型列表获取、测试、推理参数、提示词预设、最多四张参考图预设、后台任务暂停/重试/取消与刷新恢复、完整脱敏日志、本地图片持久缓存、缓存分页与容量治理、按聊天和楼层排序的跨端漫画阅读器，以及异步重绘和重新分镜。所有设置都保存在浏览器本地；参考图只发送给绘画 AI，演绎与分镜不会收到图片。

## 安装

### 在线安装（推荐）

点击 SillyTavern 顶部的扩展图标，选择“安装扩展程序”，在弹出框内填入链接：

```text
https://github.com/gemini114514/comic-orb
```

然后点击“安装”即可。

安装完成后默认进入**基础模式**，无需安装后端组件，刷新页面即可直接使用。

## 悬浮球没有出现时

打开 SillyTavern 顶部的“扩展程序”面板，找到“漫画工房悬浮球”。这里不依赖悬浮球界面，可以直接：

- 开关“显示悬浮球”；
- 点击“打开漫画球界面”；
- 运行无界面诊断并在设置区查看摘要；
- 导出不含密钥、聊天正文、参考图和图片数据的 DEBUG JSON；
- 重置跑到屏幕外的悬浮球与面板位置；
- 开启启动追踪并刷新，捕获初始化阶段异常。

如果连这个设置项也没有出现，打开浏览器开发者工具的 Console，执行：

```js
const doctor = await import('/scripts/extensions/third-party/comic-orb/diagnose.js');
await doctor.download();
```

若本地诊断模块也无法加载，可临时使用对应发布版本：

```js
const doctor = await import('https://cdn.jsdelivr.net/gh/gemini114514/comic-orb@v1.25.13/diagnose.js');
await doctor.download();
```

把下载的 `comic-orb-headless-diagnostics-*.json` 发给维护者即可。也可以先运行 `doctor.resetPosition()` 后刷新，快速排除桌面、手机、缩放比例切换造成的悬浮球坐标越界。

### 本地安装

下载仓库，把整个 `comic-orb` 文件夹放到：

```text
SillyTavern/public/scripts/extensions/third-party/comic-orb
```

重启 SillyTavern 并刷新浏览器。右下角出现铅笔悬浮球即安装成功。

## 基础模式与完整模式

### 基础模式（默认，安装即用）

浏览器直接请求用户配置的 API，不需要修改 SillyTavern，也不需要安装服务端组件。适合先体验、短任务以及允许浏览器跨域访问的 API。

顶部会持续提示两项限制：

- 超过约 300 秒的请求可能被浏览器、酒馆入口或中间代理断开；
- 部分 API 不允许浏览器跨域携带鉴权信息，此时会显示网络或 CORS 错误。

### 完整模式（慢速生图推荐）

完整模式使用仓库随附的正式 SillyTavern 服务端插件，支持最长 1800 秒请求、参考图 Multipart 转发和取消上游任务。只需在**运行 SillyTavern 后端的主机**安装一次，访问该酒馆的手机、平板和其他电脑不需要重复安装。

打开漫画球主页，点击“完整模式安装”，按实际情况选择：

- **PC 直接用**：酒馆运行在 Windows 电脑；打开漫画球目录并双击 `install-server-plugin.bat`。
- **手机直接用**：酒馆本身运行在 Android Termux；复制向导提供的一行 Termux 命令。
- **远程用**：酒馆运行在电脑、NAS、VPS 或 Docker；由主机管理员在服务器运行 `install-server-plugin.sh`，手机端无需操作。

安装脚本会链接本仓库的 `server-plugins/comic-orb`、备份 `config.yaml` 并开启官方 `enableServerPlugins` 开关。完成后重启酒馆，在漫画球顶部选择“完整模式”并重新检测。以后正常更新漫画球无需重复安装。

如需卸载服务端部分，Windows 双击 `uninstall-server-plugin.bat`；Linux/macOS 执行 `sh uninstall-server-plugin.sh /你的/SillyTavern/目录`。卸载器只移除漫画球链接，不会关闭其他服务端插件。

## 第一次配置

扩展包含三类彼此独立的 API：

1. **演绎 API**：仅在“演绎分镜模式”第一阶段使用，负责压缩剧情、整理因果并拆分故事段。
2. **分镜 API**：输出 `comic_orb_storyboard_v1` JSON；每页必须提供可独立绘制的 `page_prompt`。
3. **绘画 API**：按每页 `page_prompt` 生成图片，支持 OpenAI Images、Edits、Chat 多模态和 Gemini 原生模式。

每类 API 都能：

- 新建、保存、切换和删除多个实例；
- 导入或导出实例集；
- 获取模型列表，也可手动输入模型；
- 单独填写测试提示词；
- 保存提示词预设；
- 配置额外请求头和请求体。

分镜预设内置两档 Gemini 适配：“少年漫软适配（表现力最大）”尽量保留战斗与关系张力；“少年漫安全适配（成功率优先）”会把人形或大型变异敌人的直接头颈/身体命中特写、生物性污渍与解剖化感染环境转换为攻击轨迹、外层甲壳崩解、烟尘遮挡、环境碰撞、完整轮廓结果和非解剖化污染结构。普通蘑菇、菌林、孢子景观与非解剖化菌类怪物不会仅因题材名称被过滤。升级不会自动切换现有选择，可按题材自行选用。

总漫画工作流与异步重绘会把不可变任务快照、演绎结果、已完成分镜、图片缓存引用和已上传地址保存到浏览器 IndexedDB。任一子任务报错时只暂停总任务；按 F5、关闭标签页或重启浏览器后，未完成任务会恢复到“后台进程”的等待处理列表。点击“重试失败阶段”只补尚未完成的部分，点击“抛弃总任务”才删除工作流检查点；已生成的图片缓存不会随之删除。

当 API Base URL 指向本地 `gemini-web-to-api`（`127.0.0.1:4981/openai` 或 `localhost:4981/openai`）时，每个演绎、分镜和绘画 API 实例都可独立选择匿名/临时会话；开启后该次请求不会写入 Gemini 网页对话历史。日志页会直接显示最近一次大模型 API 原始 JSON 响应，图片 base64 与鉴权信息仍会自动省略。

演绎 API 实例可设置“演绎完成后并发分镜启动间隔”，默认 300ms、最低 100ms。第一个分镜立即启动，后续故事段依次错峰发出，避免多个长请求在同一毫秒进入服务商而触发请求突发保护；该值随 API 实例与后台任务快照保存，不影响直接分镜和绘画分页间隔。

API Key 只保存在当前浏览器 `localStorage`。导出的 API 实例 JSON 会包含 Key，请勿公开。

## 生成漫画

1. 在“制作”填写楼层范围，例如 `10-12`。
2. 选择工作流：
   - **直接分镜模式**：剧情 → 分镜 → 绘画。
   - **演绎分镜模式**：剧情 → 演绎 → 多段并发分镜 → 错峰并发绘画。
3. 设置页数、单个分镜 AI 页数和漫画文字语言。
4. 如有需要，配置剧情正则、MVU、参考图预设。
5. 点击“生成并发分页漫画并插入末层”。

范围是闭区间，默认剔除 User 楼层；即使选择发送 User 楼，也优先把漫画写回范围内最后一个非 User 楼，只有范围全是 User 楼时才使用末楼。制作按钮可启用五秒防重复提交，但不同漫画任务可以同时运行。

漫画文字语言默认是 `zh-CN`，仍可手动改为 `auto` 或其他语言。在“设置”关闭“绘制完成后把漫画插入目标楼层正文”后，任务仍会生成并持久化图片，但只保留在缓存中，不自动修改聊天正文。

制作页默认启用“不发送 User 类型楼层”；关闭后，范围内的 User 与角色楼层会一起进入剧情。正则区的“AI 辅助制作正则”会把所选范围未经正则处理的完整楼层文本和可编辑指导词发送给当前分镜 API，返回结果通过 JavaScript 正则校验后可选择追加或覆盖，并在应用前预览清洗效果。

## 后台任务

所有远端调用会进入“后台进程”：

- 演绎、分镜、绘画、上传均显示阶段和耗时；
- 任一并发子任务失败时，总流程暂停并保留成功结果；
- “重试失败阶段”只补失败或未完成部分；
- “抛弃总任务”才释放检查点；
- Cancel 会终止仍在运行的网络请求。

任务提交时会冻结剧情、正则、MVU、三套 API、参考图、页数、绘画间隔、聊天和写回楼层，运行中修改设置不会污染已提交任务。

## 参考图

每套预设最多四张图，每张图可填写对应角色或用途。参考图只发送给绘画 AI，不会发送给演绎或分镜 AI。预设库支持增删改查和整体 JSON 导入导出。

## 缓存与阅读

绘画结果会先持久化到浏览器 IndexedDB，再上传到酒馆：

- 缓存列表支持完整翻页，每页 5–50 张；
- 默认缓存上限为 512 MB，可设置 64–4096 MB；
- 接近上限时按完整生成批次清理最旧缓存，并优先清理测试图；
- 缓存页只读取当前页缩略图，不一次加载全部图片；
- 阅读器可切换聊天记录，并按楼层、漫画页码排序；
- 左右方向键切换漫画页，上下方向键切换当前页的重绘版本；手机可使用按钮或横向/纵向滑动；
- 普通阅读默认显示最新版本，从缓存列表明确打开旧版本时则准确显示所选缓存；

清理本地缓存不会删除酒馆服务器上已经插入正文的 PNG，但会失去相应提示词查看和直接重绘能力。

## 重绘

双击正文中的漫画图可打开详情：

- 直接重绘当前页；
- 重新调用分镜，再重绘整组页面；
- 查看并复制当时实际发送给绘画 AI 的提示词。

重绘是异步后台任务，不会锁死其他页面。

## 日志

普通模式只显示轻量摘要；DEBUG 可保存完整结构化请求与响应。日志导出分为：

- 最近十条；
- 全部日志；
- 大模型完整输入输出。

图片 base64、Cookie、Authorization、API Key 和 Token 不会进入导出文件；图片只记录本地绝对路径或大小摘要。

## 正则与 MVU

剧情正则采用有序列表，每条规则可独立启用。支持 JSON 导入导出和“不发送 API”的正则测试。

MVU 开启后：

- 多楼层优先发送首楼完整状态基线；
- 后续楼层只发送 JSON Patch 风格变化；
- 无法读取历史时只发送末楼当前状态；
- 直接模式只发给分镜，演绎模式只发给演绎，不重复发送。

## 安全提示

- 不要把 API 实例导出文件、日志、参考图预设或浏览器数据提交到公开仓库。
- 发布前建议运行密钥扫描并检查 Git 历史。
- 使用第三方中转时，请自行确认其隐私政策、内容规则和请求超时。
- 本扩展不附带模型额度、代理服务、Cookie 或任何第三方账号。

### TT 酒馆与代码渲染兼容

漫画页现在使用 SillyTavern 原生媒体附件写回，不再把图片 Markdown 追加到楼层正文末尾。这样不会改变原正文中代码块、HTML 容器或依赖末尾匹配的渲染结构，适用于 TT 酒馆等移动环境。旧版本写入正文的带标签漫画会在加载聊天时自动迁移；缓存 ID 与页码仍保存在附件元数据中，重绘和提示词查看功能继续保留。

每张原生媒体漫画右下角都会显示常驻的“漫画操作”按钮。手机或桌面单击按钮即可打开重绘与实际提示词页面，直接点击漫画本身仍使用酒馆原生放大；操作定位直接读取聊天附件元数据，不依赖 TT 是否保留图片 DOM 标签。

### 自动重试

设置页提供默认关闭的全局自动重试面板，可设置1–100次重试和毫秒级固定间隔。有限重试仅处理网络、超时、429及可恢复的服务端错误；全自动重试除用户主动取消外会重试所有API和响应校验错误，包括拒绝、无图、空文本及演绎/分镜JSON不合格。重试参数会冻结到新提交的漫画和重绘任务，耗尽后仍进入原有的暂停与手动重试流程。
